  • The LMCache Coordinator: a control plane for fleet-wide KV cache

    9 October 2026

    LMCache's MP mode gives every node its own KV cache server, but each server sees only itself. The coordinator is the control plane that makes them act as one cache: it builds a shared, fleet-wide view from cache events and lets pluggable policies act on it.
